Research focus

This study examines variation across reproductive stages in Arabis alpina along an elevational gradient on Mount Kenya. The archive supports exploration of:

  • flowering onset, final flowering date and flowering duration;
  • maternal seed mass, collected seed number and seed allocation;
  • germination timing, rate and percentage under shared experimental conditions;
  • conditional trait projections under mid-century climate scenarios.

The study includes 581 sampled rosettes from 27 occupied plots across nine occupied blocks. The catalogue separates current analytical outputs from historical migration records.

Provenance and reproducibility

This archive is a snapshot of the analysis folder. Data, scripts, archived model objects and run instructions are provided; a complete rerun in a clean environment has not yet been verified. RStudio caches and saved workspace sessions are excluded. Third-party climate and geographic data retain their source terms. Verify files using SHA-256 checksums ↗
